漏洞原理

由于数据库接收参数没有对用户的输入进行过滤和防护，导致参数的恶意拼接，造成数据库执行了恶意的sql语句，导致了数据的泄露和一些对数据库的恶意操作

分类

从回显：有回显的注入和盲注
从类型：联合注入、报错注入、堆叠、时间盲注、宽字节注入

联合（查询）注入
order by union imformation_shema

order by
其中order by：用来给数据库查询出来的写过按哪一列的首字母进行排序
比如 order by 3,他是前面查询出来了结果，按照第三列，数字就按大小，字母就按ascii排序，如果没那么多列就报错，所以可以用来判断表有几列

union
其中union用来合并两个以上select的查询结果，像sql手工注入里面常用的union后面加1，2，3 本质上是要和前面select 查询出来的结果列数一样才不会报错

information_shchema
mysql5.0以上才有这个数据库，维护了所有数据库的信息，包含表、列、名、权限

盲注：

布尔盲注：主要用来爆数据库名

时间盲注

不同数据库下的sql注入

最常见：mysql、sqlserver
有搭配：ssrf的redis

bypass

大小写、双写绕关键字、并发包只拦截一个包、脏数据填waf

告警流量特征

看参数，例如url的长度异常；关键字符，例如select、union，benchmark等；sqlmap的UA头等等

CSRF

跨站请求伪造，攻击者使用受害者的名义去发送恶意请求，在受害者不知情的情况下，完成恶意操作

通常需要受害者点击构造的链接或者配合XSS来打CSRF、

危害：

  1. 管理员收到攻击
  2. 非法添加管理员账户
  3. CSRF拖库
  4. 路由器的CSRF攻击

防护:

  1. 尽量使用post请求，减少get请求
  2. 使用CSRFtoken
  3. 重要后台功能加验证码

文件包含

分类

  1. 本地文件包含
  2. 远程文件包含
    • 远程加载文件在php配置文件中打开allow_url_include 开启后可以远程执行任意代码

php文件包含函数

1、include()

2、include_once()

3、require()

4、require_once()

利用

  1. 读取任意文件
  2. 配合文件上传进行打webshell
    • 图片马
    • 日志文件shell
  3. 代码执行命令
  4. 使用伪协议
  5. 截断包含

修复方案

  1. 关闭配置文件中的远程包含
  2. 过滤../来防止目录穿越
  3. 修改默认的日志存放地址，防止日志getshell
  4. 开启魔术引号
  5. 不要使用变量来调用文件，尽量写死包含哪个文件

文件上传

原理

  • 网站服务器未对用户上传的文件类型、后缀、安全性进行过滤，导致可以上传木马文件被getshell

上传姿势

  1. php一句话木马
  2. 图片马
  3. shell工具生成的木马
  4. 条件竞争

绕过方法

  1. 黑名单
    • 后缀名 php5 phptml
    • 上传.htacess
    • 大小写
    • 双写php适用于单次过滤
  2. 白名单
    • %00截断
    • 图片马
    • 条件竞争

防御方法

  1. 不采用前端验证后缀名，使用后端验证
  2. MIME验证
  3. 内容检测 - 图片马的文件头 文件完整性 文件二次渲染
  4. 上传文件更改文件名
  5. 使用WAF验证

流量特征

  1. POST请求
  2. 使用文件上传路径进行url过滤
  3. 请求体的长度异常，使用很多看起来像加密的字符

XSS

原理

通过插入恶意脚本，实现用户对浏览器的攻击

类型 反射 存储 dom

反射和dom的区别 DOMXSS是javascript处理输出，反射是XSS后台程序处理

绕过

  1. 大小写
  2. js伪协议
  3. 没有分号
  4. Flash
  5. Html5新标签
  6. Fuzz测试
  7. 双层标签绕过
